# Retired automation sources

These are historical texts, not installed skills or executable entrypoints.
The source paths and replacements are recorded in migration.json. The active
KV STUDIO operation catalog is kv-studio-operator/scripts/script_manifest.json.

Retired root forwarding wrappers duplicated role-directory entrypoints. Legacy
hardware and programmer UI scripts competed with guarded operator workflows.
Focus/menu probes are superseded by the shared implementation and regression
tests. Recover historical content from these texts or Git; do not copy it into
the active skill without reconciling the current API and testing the caller.

Normal repository searches exclude this directory via .rgignore. Search it
explicitly with rg --no-ignore only when investigating history.
