# 修改现有项目

先界定修改范围并取得相关内容的快照。KV STUDIO 项目包含同目录的关联文件，
备份应保留项目目录；只复制 .kpr 不能视为完整备份。

一次自变量修改不必导出整个项目。整项目复刻才需要完整程序、声明、类型、
设备与配置清单。使用 [operator skill](../../kv-studio-operator/SKILL.md) 查询对应接口，
允许对已打开且带未保存标记的指定项目操作。

修改流程：

1. 保存相关源快照和修改意图。
2. 准备 MNM、TSV 或配置 JSON，并完成必要的语义检查。
3. 调用公开 workflow，检查同次读回与保存结果。
4. 改动程序/声明后运行转换，按复制出的错误修复。

不要将 run_kv_mvp_repair_existing_project 当作所有修改的必经入口；
它是使用示例 scaffold 时的组合工作流。
失败时依据错误码、步骤 receipt 和 run.log 修复共享实现，再回归真实入口。
