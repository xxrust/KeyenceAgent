示例：3 轴 EtherCAT 伺服 + 2 台 IO 电机 + 23 入 / 30 出

EtherCAT 伺服 ×3IO 电机 ×2（CW/CCW）输入 23 点输出 30 点

推荐 KV-X310 一台 CPU 搞定伺服

KV-X310 自带 EtherCAT 主站口（PORT2），可控 12 轴，3 轴绰绰有余，不用另配运动单元。它还自带 16 点输入、16 点输出，这是 KV-X500 系列 CPU 没有的。

  • PDF 核实 内置输入 不分极性（光耦内反向并联双 LED，24V 电源正负极任意接），所以漏型/源型传感器都能直接接。
  • PDF 核实 内置输出是 MOSFET N-ch 漏型输出，DC30V 0.2A/点（1.6A/公共点），负载接在 +24V 与 OUT 之间。输出要工作，必须给 CPU 的 39 脚（24V）和 40 脚（0V）供电。
  • PDF 核实 X5xx（X500/520/530/550）的系统规格表里没有“CPU 单元 I/O 点数”，没有内置 I/O，且只有 X520/530/550 带 EtherCAT 口（X500 没有）。

“IO 电机”分两种情况

情况配置输入合计输出合计需求
a. 普通正反转电机（接触器/继电器切 CW/CCW）KV-X310 + KV-C32XTD（32 入 / 32 出）16 + 32 = 4816 + 32 = 4823 入 / 34 出（30 + 2×2）
b. 脉冲型步进/伺服（CW/CCW 双脉冲）KV-X310 + KV-SH04PL + KV-C16XTD（16 入 / 16 出）16 + 16 = 3216 + 16 = 3223 入 / 30 出
  • 情况 a：接触器线圈电流超过 0.2A 时，晶体管输出带不动，改用继电器输出单元（如 KV-B16RC，2A/点）或加中间继电器。
  • 情况 b：KV-SH04PL 默认就是双脉冲（正转 FP / 反转 RP），4 轴。PDF 核实 输出频率 1Hz～8MHz；用集电极开路输出时，单/双脉冲最高 200kHz，2 相 1/2/4 倍频分别 50/100/200kHz，负载电流 5～100mA。差动线驱动和集电极开路按轴用单元底部开关切换。KV-SH04PL.pdf PDF页26、43
  • 情况 b 的输出余量只有 2 点。想多留余量就把 KV-C16XTD 换成 KV-C32XTD。
  • PDF 核实 KV-C16XTD：输入不分极性，有 5V/24V 切换，输入 4.3kΩ；每点输出 0.2A（30VDC，16 点一个公共端），OFF→ON ≤100μs。KV-C32XTD：输入只有 24V 模式，每点输出 0.2A（32 点两个公共端，OFF→ON ≤150μs）。只有 KV-B8XTD 是 0.3A。KVSHARDX3H.pdf PDF页56、58；KV-7000 手册 KVSHARDG4.pdf PDF页62 一致
  • 以后要扩到十几轴以上：换 KV-X520（32 轴）。X520 没有内置 I/O，所有 I/O 都要靠单元。

下单前必须确认

  • 伺服驱动器要支持 EtherCAT CiA402，并在 KV STUDIO 里登记它的 ESI 文件。
  • KV-C32XTD / KV-B8XTD 的输入接线图（极性）还没对过原 PDF（KVSHARDX3H.pdf PDF页57、59）；X310 内置输入和 C16XTD 已核实为不分极性。
  • 接触器线圈电流超过输出单元每点电流（0.2A / 0.3A）时，晶体管输出带不动，请加中间继电器。

这是按手册规格推出的配置草案。接线、电源容量和安全回路要按实际设备设计。
