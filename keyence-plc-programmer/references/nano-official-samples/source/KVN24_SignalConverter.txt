DEVICE:134
;MODULE:Signal_converter
;MODULE_TYPE:0
;-------------------------------------------------------------------------------
;-- File        : Interrupt Routine In A Signal Converter
;-- Company     : KEYENCE CORPORATION
;-------------------------------------------------------------------------------
;-- Definition  : R000 / An input signal with very small ON width 
;               : R500 // After R000 is ON, R500 will be ON for 1 second. 
;-------------------------------------------------------------------------------
;-- Id          : v 1.0 2012/12/17
;-------------------------------------------------------------------------------
;<h1/>Example for using a signal converter to interrupt 
;Input signals with very small ON width are output according to a specific ON width using interrupt processing 
;. Small pulses of the input relay R000 are converted into pulses with ON width of 1 second that are output via R500. 
;. R500 will be ON for 1 second starting from the rising edge of the input relay R000. 
;For R000 and R500, please change the ON width according to actual usage. 
LD CR2008
EI
LD CR2002
HSP R000
LD R500
TMU #0 #100000
LD T0
RES R500
END
INT R000
LD CR2002
SET R500
RETI
ENDH
