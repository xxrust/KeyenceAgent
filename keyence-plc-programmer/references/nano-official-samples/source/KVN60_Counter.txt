;<h1/>To change the state of R1500/R1501 using the latest value of the high-speed counter 0
;Please change settings of the high-speed counter according to actual usage (INIT_CTH0 Every-scan execution module).

RFSCTH #0
LD<.D CTH0 #1000
OUT R1500
LD>=.D CTH0 #1000
AND<.D CTH0 #2000
OUT R1501
END
