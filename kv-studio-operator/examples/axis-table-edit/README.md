# 轴控制设定「大表」单元格编辑（范例 + 自包含测试）

## 核心原则（重要）
**不用像素定位 ✗** —— 屏幕分辨率/缩放一变就失效 ✗。
**用表格自己的选区导航** ✓ → 选中的是"**单元格对象**" ✓ → 与分辨率无关 ✓ 且**每步可读回验证** ✓。

## 作为测试用例（默认行为）

`run.bat`（不带参数）现在是一个**自包含测试**，包含两条用例：

| 用例 | 前置 | 期望 |
| --- | --- | --- |
| **negative** | 不启动 KV STUDIO | `set_axis_table_cell_guarded.ps1` 必须**快速失败**，错误码 `KV_TABLE_NO_KVS`；测试退出码 0 |
| **positive** | 测试自己复制 `tests/table-cell/fixtures/QA_BlankProject`、启动 KVS、打开轴控制设定 | 编辑第 39 行第 1 列为 `1500`；结果 JSON `ok=true`、diff 恰好 1 行且索引=39；测试退出码 0 |

```bat
run.bat                 :: 两条用例都跑
run.bat -Case Negative  :: 只跑反向用例
run.bat -Case Positive  :: 只跑正向用例
```

结果写入 `%TEMP%\kv-axis-table-edit-<id>\test_result.json`。测试会先结束已有的 `Kvs.exe`，请勿在测试期间手工操作 KVS。

## 作为手工范例（`-Interactive`）

```bat
run.bat -Interactive
```

1. **列出整表行号**（`index : 轴1 <TAB> 轴2`，剪贴板读取）
2. 询问 `行号 / 列(1=轴1,2=轴2) / 新值`
3. 执行：点表格(仅聚焦) → `Ctrl+Home` → `Down×行` → `Right×列` → `F2` → `Ctrl+A` → 键入 → `Enter`
4. **整表 diff**：必须**恰好一行变化**且索引 = 目标行，否则不保存
5. 保存 → 截图 → 结果 json

## 三条硬规矩
1. **坐标单位/坐标模式只能在「坐标转换计算」向导里改** ✗ 不能在大表改 ✓（改了会报「动作环境不正确，已初始化」✗）
2. 改大表前**先关掉向导** ✗（模态窗会吞掉键盘导航 ✗）
3. 必须 **F2** 进入编辑态 ✗（直接键入无效 ✗）
