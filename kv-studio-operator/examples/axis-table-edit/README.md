# 轴控制设定「大表」单元格编辑（范例，已验证 2026-10-21 ✓）

## 核心原则（重要）
**不用像素定位 ✗** —— 屏幕分辨率/缩放一变就失效 ✗。
**用表格自己的选区导航** ✓ → 选中的是"**单元格对象**" ✓ → 与分辨率无关 ✓ 且**每步可读回验证** ✓。

## 怎么用
双击 `run.bat` → 它：
1. **列出整表行号**（`index : 轴1 <TAB> 轴2` ✓ 剪贴板读的 ✓）
2. 问你 `行号 / 列(1=轴1,2=轴2) / 新值`
3. 执行：点表格(仅聚焦) → `Ctrl+Home` → `Down×行` → `Right×列` → `F2` → `Ctrl+A` → 键入 → `Enter`
4. **整表 diff**：必须**恰好一行变化** ✓ 且索引 = 目标行 ✓，否则不保存 ✓
5. 保存 → 截图 → 结果 json

## 已验证（2026-10-21 实测 ✓）
| 步骤 | 结果 |
| --- | --- |
| 读整表 | 点表格 + Ctrl+A + Ctrl+C → **79 行 TSV** ✓ |
| 选中 | `Ctrl+Home` + `Down×37` + `Right×0` → 改完 **diff 恰好 1 行** ✓ |
| 写入 | `F2` + `Ctrl+A` + 键入 + `Enter` → `40000 → 0` ✓ |
| 落盘 | 关掉重开 → 第 37 行 = `0` ✓✓ |
| 副作用 | 其余 78 行**无变化** ✓ |

## 三条硬规矩
1. **坐标单位/坐标模式只能在「坐标转换计算」向导里改** ✗ 不能在大表改 ✓（改了会报「动作环境不正确，已初始化」✗）
2. 改大表前**先关掉向导** ✗（模态窗会吞掉键盘导航 ✗）
3. 必须 **F2** 进入编辑态 ✗（直接键入无效 ✗）
