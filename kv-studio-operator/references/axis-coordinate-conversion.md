# 轴设定与坐标转换（实测整理，2026-10-20）

> 本文数据来自**界面实测**（UIA 读到的 AutomationId 与界面标签一一对应 ✓），
> 不是文档推断。复现脚本：`work/tools/Explore-MachineTypes.ps1`；原始数据：`work/template/mtype-probe/machine_types.json`。

## 1. 两个不同的界面

| 界面 | 打开路径 | 作用 |
| --- | --- | --- |
| **轴参数页** | 单元配置 → [0] KV-X520 → 运动设定 → 轴设定 → 轴n | 编码器分辨率、电子齿轮、速度/转矩等**基础参数** |
| **坐标转换计算（向导）** | 轴设定 → 轴n → **轴控制设定** → 按钮 **`坐标转换计算(C)…`**（aid `_buttonTransformCoordinator`） | 由机械配置推算 **坐标转换分子/分母** |

⚠️ 螺距/轮径/移动量**不在**轴参数页 ✗，只在**坐标转换向导**里 ✓。

## 2. 机械配置（`机械配置(M)` 下拉，共 4 种）

| 机械配置 | 参数字段 | 界面标签 | 含义 |
| --- | --- | --- | --- |
| 滚珠螺杆 | `_textBoxParameter` | 滚珠螺杠螺距(P) | 丝杠导程 |
| 皮带驱动 | `_textBoxParameter` | 皮带轮直径 | 轮径 |
| 其它 | `_textBoxParameter` | 输出轴转 1 圈的移动量 | 通用 |
| **回转工作台** | **无 `_textBoxParameter`** | （仅减速比） | 角度轴；坐标周期 360.00，坐标范围 0.00～359.99 |

⇒ **`_textBoxParameter` 的含义随类型变化** ✓；**回转工作台没有它** ✗。

## 4. 让改动生效的完整动作（实测 ✓）

```
1) 点「执行计算(E)」   ← 计算并写入页面「坐标转换分子/分母」（实测变成 1 / 400 ✓）
2) 点向导「OK(W)」    ← 应用并关闭（只点"退出向导"= 放弃 ✗）
3) 若弹「映射设定吗？」→ 点 是(Y) ✓（可能连续多个 ✓）
4) 保存（Ctrl+S；本机守卫方式已验证能落盘 ✓ All.prgx 被改写 ✓）
5) 验证：关掉重开工程 → 再进向导读 `_textBoxParameter` = 新值 ✓
```

## 7. ⚠️ 顺序坑：切换机械配置会**重置**参数（实测 2026-10-20）

```
错：先填 20 → 再切「滚珠螺杆」   ⇒ 一切换，参数回到 10 / 其它 ✗（保存的就是重置后的值 ✗）
对：先切「滚珠螺杆」 → 再填 20   ⇒ 回读 滚珠螺杆 / 20 ✓
```
⇒ 脚本 `-MachineType` 必须**先执行**，再写 `-Pitch`（已在脚本里按此顺序实现 ✓）。

## 8. 两种机械配置的实测对照

| 项 | 其它（移动量） | 滚珠螺杆（螺距） |
| --- | --- | --- |
| 写入 `_textBoxParameter` | 10 → **25** | 10 → **20** |
| `执行计算` 后 `_textBoxRatio` | **400** | **0.5** |
| 页面「坐标转换分子/分母」 | **1 / 400** | **2 / 1** |
| 重开回读 | 25 ✓ | 20 ✓（机械配置=滚珠螺杆 ✓）|

⇒ 语义：`其它` 的 ratio = 编码器10000 ÷ 移动量 ✓；`滚珠螺杆` 的 ratio = 1mm 折合转数 = 1/螺距 ✓（20mm → 0.5 转 ✓ → 分子2/分母1 ✓）。

## 10. 自绘表格的限制（重要 ✗）

- `轴控制设定` 页的表格是**自绘控件**：UIA 下 `Text/Edit` 只有 9 个（都是页头/筛选栏）✗
- ⇒ **无法**用 UIA 读写表格单元格 ✗；**只能**：
  1. 通过**坐标转换向导**（`坐标转换计算(C)`）改 4 类参数 ✓（本脚本 ✓）
  2. 其余单元格（软限位/错误/轴控制/位置控制/运转速度/JOG…）目前**无脚本通道** ✗，只能人工 ✓
- 若要覆盖全部，需要：**按坐标点点击单元格 + 键盘输入** ✓（可行 ✓ 但脆弱 ✓，且每行 y 坐标需截图确认 ✗）
## 11. 大表单元格：**对象级**选中（2026-10-21，项目所有者提出 ✓）

### 为什么不用像素 ✗
按像素点单元格在**分辨率/缩放变化**后必偏 ✗（实测：偏一行 ✗）。选中的必须是"**对象**" ✗不是"位置" ✓。

### 正确做法 ✓
```
① 点一下表格  → 只为把焦点交给这个控件（点哪儿都行 ✓）
② Ctrl+Home   → Down×行 → Right×列      ← 表格自己的选区导航 = 选中"单元格对象" ✓
③ Ctrl+C      → 剪贴板 = 当前选中的那一格（可用于校验指向 ✓）
④ F2 → Ctrl+A → 键入 → Enter           ← 写入
⑤ Ctrl+A/C 整表 → diff：必须**恰好一行变化** ✓ 且 = 目标行 ✓
```

| 步骤 | 结果 |
| --- | --- |
| 读 | 79 行 TSV ✓ |
| 选+写 | 第 37 行 `40000 → 0` ✓ **diff 恰好 1 行** ✓ |
| 落盘 | 重开回读第 37 行 = `0` ✓，其余 78 行不变 ✓ |
