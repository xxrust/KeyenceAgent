# Nano CPU 内置脉冲定位参数

公开接口：`scripts/workflows/manage_kv_nano_cpu_position.ps1`，能力 `nano_cpu_position_parameters`。当前限定本机实测的 KV-NC32 / KV STUDIO 12.41，属于 pilot。此前 KV-X 工程采用 EtherCAT 运动轴，本接口对应 Nano CPU 晶体管高速脉冲定位；不要据此推断所有 KV-X 配置都不支持其他控制方式。

入口是工具菜单 Alt+T → CPU 定位参数设定(I)。本机输入法状态下，发送字符 `i` 曾停留在工具菜单，所以接口读取并点击精确菜单对象，核对 CPU、工程完整路径、PID 和参数窗口后操作。用户已打开的其他项目不会关闭。

## 读取与应用流程

1. 新建空工程或复制工程，准备六页旧表、目标表和 JSON 契约。
2. 通过左侧树节点选择页面并核对选中状态。表格为自绘控件，UIA 不直接提供单元格内容。
3. 根据表格自身滚动条识别表格容器，点击只用于交付焦点，再用 `Esc → Ctrl+Home → Ctrl+Shift+End → Ctrl+C` 复制完整范围。复制前放置唯一哨兵，拒绝旧剪贴板和不完整表格。Ctrl+A 在这里只选择当前编辑单元格，不能作为整表快照。
4. 全部旧表先与计划逐字比较，再修改。JOG 用完整 4×3 TSV 一次粘贴；I/O 只对计划中变化的可编辑枚举单元格，通过表格行列导航粘贴，避免对固定输入格写入。每页写后与完整目标表比较，其他轴也必须一致。
5. 点击“应用”，核对参数窗仍属于同一工程且应用按钮已恢复禁用。它将参数应用到工程；不会直接写到 CPU。
6. 关闭参数窗，保存工程并关闭重开，重新读取全部六页，与目标文件逐字比较，最后关闭本次测试工程。

参数向 PLC 生效需要另行 PLC 传送／在线编辑传送。本轮只验证离线工程，未连接 PLC、未执行 JOG、回原点或电机运动。工程保存重开也不证明 CPU 掉电保持行为；手册要求根据用途配置 CPU 的掉电保持。

## 六个页面的意义

### 点参数

每轴 20 点，3 轴共 60 行，复制顺序是点 1 的轴 1、轴 2、轴 3，再到点 2。每行 8 列，最后为空注释时也保留尾随 Tab。点号用于 `PSTRT` 的点编号操作数。

| 字段 | 含义 |
|---|---|
| 动作模式 | INC 按当前坐标移动一个增量；ABS 移至绝对目标坐标；CW/CCW 为正向／反向速度控制 |
| 目标坐标／移动量 [PLS] | 脉冲数；INC 是相对量，ABS 是目标坐标。转换成 mm 或角度需要电机脉冲当量与机构参数 |
| 加速度、减速度 [Hz/ms] | 频率变化斜率，数值越大加减速越快；0 表示直接以运转速度启动／立即停止，不是 0 ms 的普通斜坡 |
| 运转速度 [Hz] | 脉冲输出频率，1～100000 Hz，需结合该轴起动速度设置 |
| 停止传感器设定 | 是否让该点接受停止传感器信号；禁用时该信号不参与此点停止 |
| 停止传感器输入后移动量 [PLS] | 0 为立即停止，1～65534 为指定剩余脉冲量，65535 表示按减速度停止 |
| 注释 | 点的业务说明；本次未修改 |

### 点参数通用设定

每轴一个“运转起动速度 [Hz]”，空项目为 200 Hz，范围 0～65535。它是点定位开始时的脉冲频率，应低于点的运转速度。它与下面 JOG 的起动速度是两项参数。

### I/O 设定

| 从 0 开始的行 | 字段 | 本机轴 1 默认值与意义 |
|---|---|---|
| 0、1 | 原点传感器输入及极性 | R000、常开；决定原点信号来自哪个输入及何种电平视为有效 |
| 2、3 | 停止传感器输入及极性 | R001、常开；与点参数中的启用及停止后移动量共同决定停止行为 |
| 4、5 | Z 相固定输入及极性 | R007、常开；配合编码器每转参考信号提高回原点重复精度，地址不能改 |
| 6、7 | CW 限位固定控制继电器及极性 | CR8012、常开；物理限位输入须在梯形图中映射到对应控制继电器，不能把这里的固定地址改成普通输入 |
| 8、9 | CCW 限位固定控制继电器及极性 | CR8013、常开；对应另一方向的限位 |
| 10 | 输出模式 | 单脉冲：脉冲＋方向；双脉冲：正转脉冲＋反转脉冲。必须与驱动器接线和输入模式一致 |
| 11 | 正方向动作时的输出脉冲 | 正转脉冲；决定坐标增加与正／反转输出的对应关系，不等于机械安装后必然向某个空间方向移动 |

KV-NC32T 的轴 1 输出为 R500/R501，轴 2 为 R502/R503，轴 3 为 R504/R505。它们是定位功能的高速输出端子，不能同时当作同一工程中其他业务的普通输出使用。此前交通灯示例也用了这些地址，因此本次采用独立空工程。

轴 2 的 Z 相是 R008，限位是 CR8112/CR8113；轴 3 是 R009、CR8212/CR8213。原点／停止可选输入按轴不同：轴 1、2 为 R000～R003 或各自系统控制继电器，轴 3 为 R004/R005 或各自控制继电器。接口禁止更改第 4、6、8 行固定输入。

NO/NC 是输入有效逻辑，不会自动完成物理限位接线或梯形图映射。手册建议物理限位尽量使用常闭型，以便断线能够被识别；最终必须核对实际接线。系统 CR 地址仅作为 CPU 参数和信号映射说明，禁止为其写标号或修改系统注释。

### 原点复归设定

| 字段 | 空项目值 | 含义 |
|---|---|---|
| 起动速度 [Hz] | 200 | 回原点起动／低速阶段频率 |
| 加速度、减速度 [Hz/ms] | 10、10 | 回原点速度变化斜率 |
| 运转速度 [Hz] | 1000 | 回原点搜索阶段频率 |
| 原点复归方向 | CCW | 开始搜索原点的方向 |
| 原点复归方法 | 原点传感器上升沿 | 选择原点识别路径；其他方法可结合传感器中点、Z 相、DOG 或接触信号，信号用途随方法变化 |
| 偏差计数器清除 | 不输出 | 选择完成回原点时是否输出驱动器偏差计数器清除信号；轴 1～3 对应 R508～R510 |
| 自动移动到初始位置 | 不移动 | 回原点后是否自动移至初始位置坐标 |
| 初始位置坐标设定值 | 0 | 自动移动的目的坐标 |

### JOG 设定

| 行 | 字段 | 默认值 | 本次测试值（轴 1） |
|---|---|---|---|
| 0 | 起动速度 [Hz] | 500 | 600 |
| 1 | 加速度 [Hz/ms] | 10 | 12 |
| 2 | 减速度 [Hz/ms] | 10 | 15 |
| 3 | 高速速度 [Hz] | 5000 | 6000 |

`JOG` 的 CW 或 CCW 条件有效时按起动速度动作，HIGH 同时有效时按设定斜率加速到高速速度。起动速度范围 1～65535，高速速度 1～100000，起动速度应小于高速速度；加减速度 0～65535。HIGH 未输入时，手册说明按起动速度起动并立即停止，不按高速段斜率执行。

这不是 `MC_Jog` 的 FB 参数，不能套用此前 EtherCAT 轴的单位和功能。按理想斜率计算，测试值从 600 到 6000 Hz 的加速约为 `(6000-600)/12=450 ms`，减速约 360 ms；这是参数含义的计算示例，未通过硬件运动测量。

### 比较器设定

比较对象是 CPU 统计的输出脉冲当前位置。比较器 0、1 可选择不使用、停止传感器、正向／反向软限位，各有一个比较坐标。比较器 2 的功能固定为中断，各轴分别显示 CR8415/CR8515/CR8615。默认比较值均为 0，比较器 0、1 均不使用。比较值为有符号 32 位坐标；中断比较值要按手册在定位相关指令执行时装入，单纯修改 CM 不能等同于当前运动中立即生效。

## 接口与验收边界

`Open` 打开参数窗；`ReadPage` 读取指定页；`ReadAll` 读取六页；`WritePage` 用完整旧表和目标表验证修改；`Apply` 应用到工程；`Close` 关闭参数窗。普通动作要求调用者管理窗口生命周期。

`ApplyPlan -ContractPath plan.json` 是完整修改路径：契约含六页按上述顺序排列的 `page/expected/source`，文件路径相对契约目录。输入在执行前冻结，先核对全部旧页，再写发生变化的 I/O 和 JOG 页，应用前再核对六页，保存重开后再核对六页并关闭工程。只有 I/O、JOG 开放写入；其他四页当前为完整读取和保持不变的验证范围。不要把可读等同于已验证可写。
