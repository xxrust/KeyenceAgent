缺口与审核问题

  • 未覆盖真实 PLC 运行时、仿真器、下载/在线监控和现场 I/O 行为。
  • EtherNet/IP 等未发布的通信配置不在本套场景中。
  • ST 编译路径以 KV-X520/KVS12 验证范围为准，不代表所有 ST 语法。
  • 02_fb_program_body 独立验证编辑和保存，不等价于编译成功。
  • 快照完整性包含 partial/unresolved warning；恢复排序仍需人工审阅。
  • 完整模块场景间接覆盖若干 UI 基元，不能替代每个基元的独立 live 用例。
  • 官方库 FB 与用户自定义 FB 的行为边界需继续补充证据。
  • 编译失败必须保持 workflow fail，再由 harness 判定 expected failure，不能把 NG 当作成功。
