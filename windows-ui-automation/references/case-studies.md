# 真实案例（KV STUDIO，2026-10-26）

这些案例用来证明方法有效，也用来提醒“下一次还会踩”。证据路径都在本机。

## 1. EtherNet/IP 设备写入（最完整的一次）

目标：脚本把 EtherNet/IP 设备加到工程里并配置。

过程与坑：

1. **首启弹窗**：`EtherNet/IP 设定` 打开后先弹“未设定…请选择设定方法”，两个按钮在 UIA 里是 **Pane 不是 Button**；按 `ControlType.Button` 过滤永远找不到。→ 改成按名字匹配任意控件，再 `SetFocus` + 空格。
2. **MFC 页签**：`设备列表/设备设定/设备查找` 是 `Afx:TabWnd`，UIA 没有 TabItem，坐标点击也常切不过去。→ 用菜单快捷键 `Alt+1/2/3`。
3. **目录网格**：设备目录是 `VSFlexGrid`，没有 UIA 行；用“点网格 → `Ctrl+Home` → 逐行 `Down` + 读窗口 `Static` 详情文本”定位机型，命中后回车。
4. **加入弹窗**：回车后出现 `适配器初始设定`，显示 KV 自动分配的节点地址/IP；点 OK。
5. **弹窗风暴**：主窗口 OK 后依次出现 `设定信息被更改`（是(Y)）→ `更新单元编辑器`（确定）→ `EIP 设备更新，创建设备连接用变量`（确定）→ `EtherNet/IP设备 变量设置`。顺序不稳定，第一次只等到一个就失败。→ 统一“任意已知弹窗”循环，变量命名对话框直接 `WM_CLOSE`。
6. **WinForms 按钮**：这些弹窗里的“确定”对 `BM_CLICK` 无反应，`Invoke()` 会阻塞。→ `SetFocus()` + 空格。
7. **自动分配值**：配置写 `192.168.0.2`，实际 KV 分配 `.6`。→ 回读实际值，不假设等于请求值。
8. **回读**：重开 EIP → 点 `设定列表` 网格 → `Ctrl+A/Ctrl+C`，比较写前/写后 IP 集合，出现新 IP 才算成功。

结果：退出码 0，回读新增 `192.168.0.6`。
证据：`C:\kvrun\eip_write_dl_run6\eip_write.log`、`success.png`。

教训：
- 弹窗不是“点掉一个”，而是一类状态机。
- 目录/表格这类自绘控件，**读静态文本/剪贴板** 比找控件节点可靠。
- 成功判据必须是“目标集合新增”，不是“脚本没报错”。

## 2. EtherCAT 设备添加：双击被截图打断

现象：`KV_ETHERCAT_NODE_ADDRESS_EDITOR_NOT_FOUND`，双击设备加不上。

根因：守卫函数在两次点击之间插入截图（约 200–300ms），系统把它当成两次单击。

修复：新增 `Invoke-KvGuardedDoubleClick`，两次 click 间隔 60ms，只在前后各截一张。

教训：**双击/组合键是原子动作**，中间不能有任何 IO。

## 3. EtherCAT 保存：预算不足

现象：`KV_ETHERCAT_ATOMIC_STEP_TIMEOUT`（11s）。

根因：保存 + 5 个已知弹窗需要 >10s，原 deadline 太短。

修复：`-BudgetMs 30000`，deadline 25s，并把 5 个弹窗按“标题+正文”固化匹配。

教训：等待要有预算和判据；超时不是“再跑一次”。

## 4. 轴改名：页面字段只读

现象：改轴名“成功”但树里没变。

根因：`轴名称` 页面输入框是只读的显示控件；真正入口是 `属性` 对话框。

修复：点 `_buttonEditAxisProperty` → 等 `属性` WinForms 对话框 → 枚举子窗口 → `WM_SETTEXT` 第二个 `WindowsForms10.Edit` → `BM_CLICK` OK → 回读树文本。

教训：
- “字段存在”不等于“字段可写”。
- 同名重命名测试会产生假阳性；要用不同名字断言。

## 5. EIP 读取快照：表格只能剪贴板

现象：`软元件分配设定` 的 199 行分配表，UIA 读不到任何单元格。

修复：点单元格 → `Ctrl+Home` → `Ctrl+Shift+End` → `Ctrl+C`，得到 TSV 再解析。

教训：**剪贴板是自绘表格的通用读接口**，但需要先让网格拿到焦点。

## 6. 通用教训汇总

| 教训 | 一句话 |
| --- | --- |
| 身份 | 类型 + 标题 + 正文，三者缺一不可 |
| 焦点 | 点击前必须确认前台，失败就报错 |
| 原子 | 双击/组合键是一个动作，中间不 IO |
| 弹窗 | 当状态机处理，不当单点处理 |
| 回读 | 写后独立验证，差集证明新增 |
| 句柄 | 每次重查，不跨步骤缓存 |
| 假绿 | 没有回读就不许报成功 |
